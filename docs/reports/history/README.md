# Report History

Use this folder for preserved phase plans, legacy design inputs, and other historical planning artifacts that are still worth keeping readable.

Rules:

- Nothing here is current source of truth by default.
- If a fact is still current, copy it into `design/`, `docs/domain/`, or `docs/runbooks/`.
- Keep files here only when they help explain past migrations, previous thinking, or release history.

Examples:

- phase plans kept for historical context
- legacy design documents that were superseded by the current design corpus
- migration-input documents retained for traceability
