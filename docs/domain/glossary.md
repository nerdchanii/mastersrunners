# 도메인 용어 사전

## 핵심 엔티티

| 용어        | 영문             | 현재 의미                                                    |
| ----------- | ---------------- | ------------------------------------------------------------ |
| 워크아웃    | Workout          | 러닝 기록 단위. 포스트와 분리된 운동 데이터                  |
| 포스트      | Post             | 텍스트, 이미지, 해시태그, 연결된 워크아웃을 담는 소셜 콘텐츠 |
| 크루        | Crew             | 멤버십, 활동, 게시판, 채팅을 가진 그룹                       |
| 크루 활동   | CrewActivity     | 공식 모임 또는 번개 모임                                     |
| 크루 출석   | CrewAttendance   | RSVP/체크인/노쇼 상태를 가진 활동 참석 기록                  |
| 챌린지      | Challenge        | 목표 기반 참여 이벤트                                        |
| 이벤트      | Event            | 대회/이벤트 레코드                                           |
| 이벤트 참가 | EventParticipant | 이벤트 등록, 결과, 워크아웃 연결을 담는 참가 기록            |
| 신발        | Shoe             | 개인 소유 러닝화 레코드                                      |
| 대화        | Conversation     | DIRECT, CREW, ACTIVITY 대화방                                |
| 메시지      | Message          | 대화방 안의 개별 메시지                                      |

## 현재 canonical 기준에서 제거된 오래된 용어

아래 개념은 과거 문서에는 남아 있었지만, 현재 canonical 모델이 아니다.

- 이벤트를 여러 종목 모델로 분리하는 구조
- 참가 결과를 별도 결과 엔티티로 분리하는 구조
- 공유 카탈로그 / 개인 소유 / 리뷰를 나누는 신발 3분할 구조

이 용어들이 다시 필요해지면 새 설계나 ADR로 복귀시켜야 한다. 현재 도메인 문서의 기준으로 사용하지 않는다.
