# Plans

This folder holds historical or transitional implementation plans.

## Rules

- `docs/plans/archive/` stores preserved historical phase plans and completed backlog material.
- report-like documents belong in `docs/reports/`.
- durable design must be copied into `design/` or synced into `docs/domain/` before it counts as current source of truth.
- files that remain in `docs/plans/` root are migration inputs only, not canonical current-state docs.

New large changes should prefer:

- `design/initiatives/` for the big-change framing
- `tasks/` for execution state
