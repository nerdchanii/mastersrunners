# PO Review Checklist

Review in this order:

1. Check the task goal and done criteria against the actual change.
2. Check whether the change improves the intended user or operator experience.
3. Check whether scope was hidden, silently shrunk, or expanded without being documented.
4. Check whether specialist findings leave blocking release risk.
5. State clearly whether the current changeset can be closed now.
