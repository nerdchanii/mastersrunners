# UI/UX Review Checklist

Review in this order:

1. Check whether the screen shows product content before explanation.
2. Check whether gated actions trigger at the right boundary and preserve route context.
3. Check copy tone for demo, placeholder, or over-explaining language.
4. Check hierarchy, affordance clarity, and responsive legibility.
5. Check whether the result still feels like a runner social product rather than a generic dashboard or landing page.
