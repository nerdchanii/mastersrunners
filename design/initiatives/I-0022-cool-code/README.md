## Approved Layering

| Layer                       | Owns                                                                           | Must Not Own                                           |
| --------------------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------ |
| `AppProviders`              | `QueryClientProvider`, theme/auth/realtime/toaster provider 조합               | route recovery, route fallback, navigation policy      |
| Route/Layout Composite Root | `Outlet`, route-level fallback, `QueryErrorResetBoundary` 연결                 | endpoint, query key, mutation invalidation             |
| Route Loader                | route-critical query prefetch via `queryClient.ensureQueryData(queryOptions)`  | direct `api.fetch`, independent router cache ownership |
| Route Page Hook             | route params, active tab, navigation callback, auth gate orchestration         | API URL, cache defaults, optimistic cache writes       |
| Domain Query/Mutation Hook  | endpoint, key factory, `enabled`, `select`, invalidation, optimistic rollback  | layout, modal visibility, route redirect               |
| Feature Composite Root      | section composition, ephemeral UI state, callback wiring, data-to-prop shaping | endpoint, auth redirect, cache policy                  |
| Presentational Leaf         | deterministic rendering and event callbacks                                    | fetch, query key, mutation side effects                |
