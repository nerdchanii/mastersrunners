# Docs Review Checklist

Review in this order:

1. Confirm the task scope and changed docs match each other.
2. Check whether the docs still point to the right source-of-truth files.
3. Look for wording that weakens approved design or domain truth to match implementation shortcuts.
4. Check structure, headings, and cross-references for navigation quality.
5. Flag stale examples, hidden divergence, and contradictory workflow instructions.
